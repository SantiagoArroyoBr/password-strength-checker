# Password Strength Checker

Proyecto básico que marca el inicio de mi portafolio en programación y ciberseguridad.

Es un checker de fuerza de contraseñas que evalúa:
- Longitud (mínimo 9 caracteres, ideal 12 o más)
- Uso de mayúsculas
- Uso de números
- Uso de caracteres especiales/símbolos

## Requisitos

Solo necesitas tener Python instalado.

## Cómo correrlo

Desde la terminal:

Python main.py

O ábrelo y corre `main.py` directamente desde tu editor de código.

## Qué aprendí

Este proyecto me sirvió para practicar:
- Paso de variables entre funciones (parámetros y `return`)
- Recorrido de strings caracter por caracter
- Lógica booleana (`and`, `not`) para combinar condiciones
- Organización de un programa en funciones con responsabilidad única
